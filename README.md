# calmcom-legal

Public privacy policies and text message terms for businesses that use CalmComAI's ordering assistant.
Served by GitHub Pages at https://legal.calmcomai.com.

- One folder per business: `/<business>/privacy/` and `/<business>/terms/`.
- Shared look: `assets/style.css`; fonts: Inter Tight (SIL OFL 1.1), self-hosted in `assets/fonts/`.
- Logos: `assets/<business>-logo.png` (light logo, transparent background).
